## Проект "Веб-приложение на Django, которое позволяет пользователям управлять рассылками сообщений для клиентов"

## Цели проекта
+ Приложение должно включать функциональность для создания, просмотра, редактирования и удаления рассылок, а также отправки сообщений по требованию. с помощью django

## Используются следующие зависимости:

- poetry add django
- poetry init
- pathlib
- poetry add --group lint flake8 black mypy isort 
- ipython
- Pillow
- python-dotenv
- psycopg2-binary
- зависимость с яндекс почтой
- сгенерирован пароль 
- redis
- secrets 


## Использование:
+ Создан проект Web_application_django
+ Зарегистрировано приложение  mailing_service
+ Созданы модели Recipient, Message, Mailing, MailingLog, User и добавлены в админ
+ Созданы html страницы home и contacts, добавлена маршрутизация, вывод последних 5 продуктов
+ Подключены стили bootstrap 5
+ Подключена база данных и сделаны необходимые миграции для работы проекта
+ Сформированы фикстуры и добавлена кастомная команда create_manager_group, send_mailings
+ Написаны контроллеры для домашней страницы и страницы с контактной информацией
+ Реализована форма обратной связи на странице контактов
+ Подключена база данных и сделаны необходимые миграции для работы проекта
+ Добавлен шаблон главной страницы, на которой отображена статистика рассылок
+ Навигационная панель, подвал и стили вынесены в отдельные шаблоны 
+ Контроллеры приложения mailing_service почти все переведены на CBV
+ Добавлено приложение users, модель пользователя с использованием AbstractUser, кастомная команда по созданию пользователя
+ Форма для регистрации, авторизация по электронной почте и паролю
+ Закрыт доступ к страницам, связанным с управлением продуктами и возможность восстановить пароль
+ Добавлен интерфейс редактирования профиля пользователя
+ Реализованы несколько групп и определены права для них, создана фикстура с группами 
+ В модели добавлен атрибут owner, который заполняется автоматически
+ Настроено кеширование для страницы base и списка пользователей декоратором
+ Добавьте низкоуровневое кеширование для списка продуктов
+ Создана сервисная функция для работы с продуктами, которая возвращает список всех продуктов в указанной категории.
+ Сервер запускается с помощью команды python manage.py runserver
+ Сервер останавливается командой CTRL+C
